First-Principles Floc Density Analysis
======================================================================

METHODOLOGY
----------------------------------------------------------------------
Path 1 (Stokes): Δρ = 18μw_s / (gD_f²)
  Assumptions: Stokes drag (Re << 1)
  Uses: w_s (measured), D_f (measured)

Path 2 (Fractal): φ = (D_f / D_p)^{n_f - 3}
  Assumptions: Self-similar fractal packing
  Uses: D_f (measured), D_p (from intersections), n_f^3D (from MCMC)

Path 3 (Cross-check): ρ_s,eff = ρ_w + Δρ / φ
  Assumptions: None beyond Paths 1 + 2
  Expected: ≈ 2650 kg/m³ (kaolinite) if consistent
