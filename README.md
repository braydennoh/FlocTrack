# FlocProject

## Video Tracking Algorithm

**[FlocTrack](https://github.com/braydennoh/FlocTrack/blob/main/FlocTrack.ipynb)** is a tool for analyzing floc particle motion in floc tank experiments. It extracts frames from video, processes images, and tracks floc particles to measure their **diameter** and **velocity** over time.

## Features
- **Frame Extraction** – Captures frames from a specified time range in the video.
- **Image Processing** – Computes average grayscale images for enhanced analysis.
- **Floc Tracking** – Measures floc diameter and velocity to analyze particle dynamics.

This tool automates data extraction for floc characterization in flume tank experiments.
